Overview

Ceylon Traveler is a travel and accommodation booking platform for Sri Lanka that I built on my own with MongoDB, Express, React and Node.js. Travellers can book hotels, taxis and guides in one place.

Problem

Travellers in Sri Lanka usually book hotels, taxis and guides in different places. This brings them into one booking flow.

What I built. A MERN platform for booking hotels, taxis and guides, with availability checks and JWT authentication.

My role

Solo project. I designed the MongoDB schema, built the REST API in Node.js and Express, and built the React front end.

Architecture

Key features

  • Hotel, taxi and guide booking in one place.
  • Availability checks before a booking is confirmed.
  • JWT-based authentication.

Tech decisions

  • Hotels, taxis and guides share one booking flow and one login, instead of three separate systems.
  • Availability is checked before a booking is confirmed.
  • JWT-based authentication protects booking actions on the API.

Challenges & what I learned

  • Fitting three different kinds of booking into one MongoDB schema without making the data hard to query.
  • Building it solo meant owning every layer, from the database schema to the React front end.
